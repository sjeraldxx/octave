# Octave

Private reading log for the year: **four shiftings × eight weeks × seven courses**.

Coverage, reading progress, revision notes, practice exams you write and sit, and a weekly confidence score. Everything stays in the browser you open it with.

## Live

[https://sjeraldxx.github.io/octave/](https://sjeraldxx.github.io/octave/)

Laptop and iPad do not share the same log. Use **Progress → Save transfer file**, then restore on the other device.
